---
title: Does the choice of programming language affect how many defects software has?
summary: Language features such as static typing are often claimed to prevent bugs. Do programs written in some languages really contain fewer defects?
area: quality
---

## Why it matters

Language choice is a long-lived decision that is expensive to reverse. If language features measurably reduce defects, that should weigh heavily in the choice; if the effect is small or confounded by who uses which language, other factors matter more.

## Scope

Includes associations between programming languages or type systems and defects in real projects, and the share of real bugs that a type system would detect. Excludes performance and developer productivity.
