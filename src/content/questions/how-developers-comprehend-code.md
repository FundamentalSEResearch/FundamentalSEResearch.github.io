## Why it matters

Naming conventions, code layout, documentation, and tools all assume some model of how developers read code. If comprehension is driven by expectations and recognizable clues, code that matches conventions is easier to understand; if it is built from the statements up, other properties of the code matter more.

## Scope

Includes the strategies, knowledge structures, and mental representations developers use when reading programs, studied by behavioral experiments and neuroimaging. Excludes the readability of specific languages or tools.
