## Why it matters

Debugging and code navigation tools embody an assumption about how developers search. If navigation follows cues such as words shared between a bug report and the code, tools can predict and support it; if it follows hypotheses, tools must support reasoning instead.

## Scope

Includes how developers choose which code to inspect next during debugging and maintenance tasks. Excludes automated fault localization techniques that do not involve developers.
