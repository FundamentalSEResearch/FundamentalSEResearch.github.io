---
title: Does higher test coverage mean more effective tests?
summary: Coverage is the most widely used measure of how well software is tested. Does a test suite that covers more code also find more faults?
area: quality
---

## Why it matters

Organizations set coverage targets and judge test suites by them. If coverage tracks fault-finding ability, it is a cheap proxy for test quality; if it does not, coverage targets can reward tests that execute code without checking it.

## Scope

Includes statement, branch, and related coverage criteria, and test suite effectiveness measured by mutation analysis or real faults. Excludes the effectiveness of particular test generation tools.
