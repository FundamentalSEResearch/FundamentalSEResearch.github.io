---
title: Do different verification techniques find different defects?
summary: Testing, code reading, and inspection all find defects. Is one technique clearly best, or does each find kinds of defects the others miss, so that combining them pays off?
area: quality
---

## Why it matters

Teams must decide how to split verification effort. If techniques are complementary, a mix beats concentrating on the single best technique; if one dominates, effort should go there.

## Scope

Includes comparisons of testing strategies, code reading, and inspections in terms of the number and kinds of defects detected and the effort required. Excludes automated static analysis tools.
