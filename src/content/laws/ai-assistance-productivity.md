## Statement

AI assistants generate code from natural language and context, so developers using them spend less time writing code and complete tasks faster.

## Notes on evidence

Randomized experiments disagree. Gains are reported for self-contained tasks, while experienced developers working in large code bases they know well were slowed down, even though they believed they were faster. The effect likely depends on the task, the developer's familiarity with the code, and the tools available at the time.
