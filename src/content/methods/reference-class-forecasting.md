---
name: Reference class forecasting
kind: engineering
summary: Estimate a new project by placing it in the distribution of outcomes of comparable past projects (the outside view), rather than reasoning only from its own plan.
references: [flyvbjerg-2006]
---

An engineering method derived from the [Planning Fallacy](/theories/planning-fallacy/). It counters the inside-view bias by forcing the estimator to start from base rates.
