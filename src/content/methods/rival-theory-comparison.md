---
name: Rival theory comparison
kind: research
summary: Test two or more competing theories against the same data, coding the evidence for each theory's propositions, instead of testing one theory against a null hypothesis.
references: [ralph-2015-process-theories]
---

Follows Platt's strong inference: the useful question is usually not whether a theory is correct but which of the plausible alternatives explains the data better. A null hypothesis is often a straw man that any reasonable theory will beat. Comparison suits process theories, which have no independent and dependent variables to manipulate. It can be applied to case data (a coding scheme per theory, or per conflicting proposition) and to questionnaires (bipolar items with one pole per theory).
